백엔드로 시작해 프론트엔드로 영역을 넓혀왔습니다. 화면에서 발견한 문제를 API 응답과 원천 데이터까지 따라가며 원인을 찾고, 필요한 개선을 직접 적용합니다.

이미지와 폰트 로딩을 최적화해 LCP를 19.8초에서 2.5초로 줄였습니다. AWS ECS와 CodePipeline으로 프론트엔드 배포를 자동화하고, Playwright 기반 E2E 테스트로 주요 사용자 흐름을 검증하는 환경을 구축했습니다.

강의와 멘토링으로 실무 경험을 나누고, 배운 내용은 기술 블로그에 기록합니다. 동료와 지식뿐 아니라 문제의 맥락을 공유하며 더 나은 결과를 만들어가고자 합니다.
